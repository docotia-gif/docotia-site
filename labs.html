Docotia Labs

Software, built by non-programmers.

Docotia Labs is where we build tools that solve real problems for real people. Our first release, the Amputee BMI calculator, is a free web tool that adjusts body mass index for limb loss after amputation — something standard BMI calculators get wrong. Try it now at amputeebmi.com, or see the app in action.

LimbView, a session logger for mirror imagery practice, is coming soon to the App Store. Learn more about LimbView.

Other tools in development: Amputee BMI (native iOS version), and more session tools for visual practice. Check back soon.
