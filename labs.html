Docotia Labs

Software, built by non-programmers.

Docotia Labs is where we build tools that solve real problems for real people. Our first release, the Amputee BMI calculator, is a free web tool that adjusts body mass index for limb loss after amputation — something standard BMI calculators get wrong. Try it now at amputeebmi.com.

Next up: LimbView, a mirror-therapy companion app for visual and motor imagery practice. Amputee BMI, a native iOS version of the calculator. More tools are in development — check back soon.
